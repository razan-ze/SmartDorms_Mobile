# 🏠 UniStay – Student Accommodation App

UniStay is a mobile application developed using **Flutter and Dart** that helps students discover and explore available student dormitories. It provides a simple and convenient experience for browsing accommodation options, managing favorites, and updating personal profiles.

Developed as a university project, UniStay combines mobile development, backend integration, and database management to deliver a complete student-facing application.

## ✨ Features

- **Splash Screen & Landing Page** – Welcome experience for students.
- **Browse Dormitories** – Explore available student accommodation options.
- **Dormitory Details** – View information about individual dormitories.
- **Favorites Management** – Add or remove dormitories from favorites.
- **Favorites List** – Easily access saved accommodation options.
- **Student Profile** – View and edit personal information.
- **Secure Logout** – Log out of the application.

## 🏗️ Architecture

UniStay uses a **client-server architecture**:

- **Frontend:** Flutter mobile application responsible for the user interface and interactions.
- **Backend:** REST APIs responsible for handling requests and application logic.
- **Database:** MySQL for storing and managing application data.

The mobile application communicates with the backend APIs to retrieve and update information.
